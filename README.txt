Empty Classroom

Empty Classroom is a website where CUNY Students can find classrooms that are currently not in use and book/reserve these rooms as their own personal study space!

Features:
    - allow booking and rating/reviews of rooms
    - room recommendations
    - student event scheduler

Using Selenium, the CUNY Global Search Enrollment site is scraped to automate collection of classroom availabilities.
MySQL and Google Cloud Platform to store and access this data in the cloud.
Django is web framework
Pytorch for room recommendations
